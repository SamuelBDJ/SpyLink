# SpyLink — Geolocation Link Tracker

SpyLink is a web application designed to create trackable links and analyze visitor interactions.

The project explores consent-based geolocation, visitor identification, link tracking, and analytics through a modern web stack.

## 🚀 Features

- Create and manage trackable links
- Generate unique visit IDs
- Collect visitor IP information
- Request geolocation through the browser Geolocation API
- Store visitor and interaction data
- Track link visits
- Web dashboard for project management
- REST API
- Database persistence

## 🛠️ Tech Stack

- Python
- FastAPI
- Jinja2
- SQLite
- HTML
- CSS
- JavaScript
- Git & GitHub

## 🏗️ Project Status

🚧 **In development**

SpyLink is currently being developed as a portfolio project, with plans to expand its analytics, privacy controls, authentication, database architecture, and deployment infrastructure.

## 🔐 Privacy

SpyLink is designed around responsible data collection. Geolocation data is requested through the browser's permission system and should only be collected with the visitor's consent.
